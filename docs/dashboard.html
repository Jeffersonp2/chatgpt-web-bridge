Endpoints e integrações

Base URL: http://127.0.0.1:4310/v1. As chamadas dependem de uma sessão autenticada no ChatGPT Web.

Autenticação

Se LOCAL_API_KEY estiver definida, envie X-API-Key: SUA_CHAVE ou Authorization: Bearer SUA_CHAVE em todas as rotas /v1/*. Fora do loopback, a chave é obrigatória.

O dashboard usa DASHBOARD_TOKEN separado.

Sessões e modelos

O padrão é session_id=default. Passe session_id no corpo ou X-Session-Id no cabeçalho para separar conversas por contato. Modelos: chatgpt-web, -instant, -thinking, -pro.

Exemplos de chamadas

Remova o cabeçalho X-API-Key somente se o bridge estiver em loopback e LOCAL_API_KEY estiver vazia.

Chat

curl http://127.0.0.1:4310/v1/chat/completions \
  -H 'X-API-Key: SUA_CHAVE' -H 'Content-Type: application/json' \
  -d '{"model":"chatgpt-web","session_id":"cliente-1","messages":[{"role":"user","content":"Olá!"}]}'

Imagem, áudio ou arquivo recebido

curl http://127.0.0.1:4310/v1/chat/completions \
  -H 'X-API-Key: SUA_CHAVE' \
  -F 'model=chatgpt-web' -F 'session_id=cliente-1' \
  -F 'messages=[{"role":"user","content":"Analise o anexo."}]' \
  -F 'include_base64=true' -F 'file=@arquivo.pdf;type=application/pdf'

Responses API

curl http://127.0.0.1:4310/v1/responses \
  -H 'X-API-Key: SUA_CHAVE' -H 'Content-Type: application/json' \
  -d '{"model":"chatgpt-web","input":"Explique HTTP em uma frase."}'

stream: true ativa SSE. O cabeçalho X-TesteGPT-Stream-Granularity: ui-delta informa que os deltas vêm da interface. Para arquivos gerados, solicite include_base64: true e use files[].b64_json quando disponível; a URL pode expirar.

Integrações com WhatsApp via n8n

O testeGPT fornece a API local; o n8n recebe webhooks, obtém mídias do provedor, chama o bridge e envia a resposta. O n8n precisa alcançar o endereço do bridge. Dentro de um contêiner, 127.0.0.1 aponta para o próprio contêiner.

Evolution API v2

  1. Importe n8n-whatsapp-evolution.json no n8n.
  2. Configure o webhook da instância com MESSAGES_UPSERT e webhookBase64: true, apontando à Production URL do nó Evolution Webhook.
  3. Nos nós Bridge, defina a URL alcançável e a credencial Header Auth X-API-Key. Nos nós de envio, defina a URL, a instância e a credencial apikey da Evolution.
  4. Teste texto, áudio, imagem, PDF e envio de arquivo gerado antes de ativar o fluxo.

Guia completo da Evolution API

WhatsApp Business Cloud (Meta)

  1. Importe n8n-whatsapp-meta.json no n8n.
  2. Configure as credenciais dos nós WhatsApp, a credencial Bearer da Meta para download de mídia e X-API-Key para os nós Bridge.
  3. Substitua SEU_SERVIDOR e SEU_PHONE_NUMBER_ID, ative o fluxo e teste texto, mídias e arquivo gerado.

Guia completo da Meta

Antes do uso contínuo, configure deduplicação persistente por ID da mensagem no n8n. Reentregas de webhook podem gerar respostas duplicadas. Mantenha credenciais apenas no n8n e exponha o bridge por HTTPS ou rede privada com LOCAL_API_KEY e DASHBOARD_TOKEN distintos.

Limites e comportamento

  • JSON: JSON_LIMIT=50mb; multipart: até 20 arquivos, MAX_UPLOAD_MB=40 por arquivo.
  • URLs de anexos remotos são limitadas por tamanho, tempo e destino. Arquivos privados do WhatsApp devem ser baixados pelo n8n com a credencial do provedor.
  • IDs de sessão aceitam até 64 caracteres: letras, números, ponto, sublinhado e hífen.
  • Erros da API usam {"error":{"message":"...","type":"..."}}. Códigos comuns: 400 entrada inválida, 401 autenticação, 502 falha no ChatGPT Web e 503 configuração indisponível.
  • A interface do ChatGPT pode mudar. O streaming fornece deltas da UI, sem garantia de um evento por token.
